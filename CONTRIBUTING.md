# Contributing

Thank you for your interest in cp-reminders.

cp-reminders is an experiment, and it may be kept or scrapped depending on how it goes. For now it is not accepting outside contributions, whether issues or pull requests.

The one exception is the bot misbehaving, for example posting a wrong or duplicate reminder or missing a contest: you are welcome to open an issue saying what happened and when.

Issues and pull requests with no activity for 7 days are labelled `stale` and closed 30 days later; a comment removes the label at the next run. Items labelled `pinned`, `security`, `help wanted` or `good first issue` are never marked or closed, and neither are pull requests labelled `dependencies`, which Dependabot adds to its own. If one of these labels is added to an item that is already `stale`, the `stale` label stays until it is removed by hand.

If you would like to contribute to MITAoE projects, [mitaoe/pyqs](https://github.com/mitaoe/pyqs) and [mitaoe/notes](https://github.com/mitaoe/notes) welcome contributions.
